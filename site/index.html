HLTH-01The Australian sitemap lists 286 URLs, all on the NZ domainHigh›
$ curl -sL https://healtheries.com.au/sitemap.xml | grep -o '<loc>https://[^/]*' | sort | uniq -c
    286 <loc>https://healtheries.co.nz

Fix: generate one sitemap per domain. The likely cause is the generator reading the NZ site URL from shared config.

HLTH-02Pages that don't exist return HTTP 200 (soft 404)High›
$ curl -sL -o /dev/null -w '%{http_code}\n' https://healtheries.com.au/any-made-up-path
200   # page title: "Page Not Found"

Fix: return a real 404 with notFound() (App Router) or { notFound: true } (Pages Router).

HLTH-0374 of 167 product URLs return HTTP 500High›
$ curl -sL https://healtheries.co.nz/sitemap.xml | grep -o '<loc>[^<]*/product/[^<]*' \
    | sed 's/<loc>//' | xargs -P 8 -I{} curl -s -o /dev/null -w '%{http_code}\n' {} | sort | uniq -c
     93 200
     74 500

Fix: a removed product should return 404 or 301, never 500. The work order lists all 74 URLs.

HLTH-04Homepage <title> is "Home". WordPress already has the right one.High›
$ curl -sL https://healtheries.com.au/ | grep -oE '<title>[^<]*|og:title" content="[^"]*'
<title>Home
og:title" content="Home - Healtheries

Fix: build <title> from the same Yoast field the front end already uses for og:title.

HLTH-05Structured data exists in the CMS but never reaches the pageHigh›
$ curl -sL https://healtheries.com.au/ | grep -c '<script type="application/ld+json"'
0   # Yoast's schema graph is in the payload as escaped text, with URLs on api.healtheries.au.production.beingbui.lt

Fix: render the Yoast schema as a JSON-LD tag with the public host, and add Product schema. This is how AI and Google read price, ingredients and availability.

HLTH-06No canonical tags, no hreflang between AU and NZHigh›
$ curl -sL https://healtheries.com.au/ | grep -cE 'rel="canonical"|hreflang'
0

Fix: add a self-referencing canonical, plus reciprocal en-AU / en-NZ hreflang between matching pages.

NL-01Nutra-Life AU and NZ each point only to themselvesHigh›
$ curl -sL -A "Mozilla/5.0" https://nutralife.com.au/ | grep -o 'hreflang="[^"]*" href="[^"]*"'
hreflang="x-default" href="https://nutralife.com.au/"
hreflang="en" href="https://nutralife.com.au/"
hreflang="zh-Hans" href="https://nutralife.com.au/zh"

Why: they share products (Gut Relief, Magnesium Sleep, Probiotica) and compete with each other for the same searches. Fix: reciprocal en-AU ↔ en-NZ hreflang on both sites.

NL-02The NZ site declares itself AustralianMedium›
$ curl -sL https://www.nutralife.co.nz/ | grep -oE '<html[^>]*lang="[^"]*"|"inLanguage":"[^"]*"'
<html lang="en-AU"
"inLanguage":"en-AU"   # ×3

Fix: one setting. Settings → General → Site Language → English (New Zealand). It fixes all four values.

06 · How we improve it

Find. Fix. Prove it moved.

Each month we re-ask the same questions across every AI and re-scan all six sites. What we change in between is measured against that baseline.

1

Fix what's broken

Healtheries and the Nutra-Life AU/NZ conflict. If a crawler can't read a page, AI can't recommend the product.

2

Publish the facts AI looks for

Protein per serve, third-party testing, ingredients and price, as structured data and store answers. These are facts from the label, not AI-written copy.

3

Be on the pages AI reads

Complete listings at the retailers it cites, and products submitted to the comparison sites. The cited-sources data becomes the to-do list.

4

Measure it monthly

The same questions, every model, every month. Share of AI answers is the number that matters.

Everyone sells find. Almost nobody sells fix.

Closes automatically

Shopify

musashi.com · nutralife.com.au

The agent drafts the change through the Shopify Admin API, a person approves it, and it's applied and logged with before/after. Every change can be rolled back.

Closes with access

WordPress / Woo

nutralife.co.nz · aussiebodies.com

With a scoped application password, same as Shopify. Without one, the agent writes a work order.

Closes with a work order

Agency Next.js

healtheries.com.au · .co.nz

The agency owns the code. Each ticket includes URLs, expected output and a one-line acceptance test, and the re-check closes it.

08 · What's next

Headless shopping.

The next shopper may not visit the website at all. Their agent will: it compares products, asks the store questions and checks out on their behalf. Whatever the agent can't read, it can't buy.

Sep 2026 · US first

Meta Muse

A personal agent that browses stores and completes a purchase through Stripe Link once the user approves the amount.

2026 · via text message

Instinct

A personal agent that lives in your messages and uses the apps and accounts you already have to get things done, including buying.

Jan 2026 · Shopify + Google

Checkout inside AI

Google and Shopify's Universal Commerce Protocol lets agents check out in AI Mode and Gemini. OpenAI's equivalent powers checkout inside ChatGPT.

Shopify stores: nearly there

Musashi and Nutra-Life AU score 5 of 6. The gap is the store's knowledge base: load it with the facts from the label (protein per serve, testing, dosage, who it's for) and agents get an answer instead of an empty reply. After that, turn on Shopify's agentic checkout channels as they reach Australia.

Everything else: start with product data

Healtheries, Aussie Bodies and Nutra-Life NZ score 1 of 6. An agent can find their product URLs but can't reliably read a price, stock level or barcode from them. Structured product data comes first, and for Healtheries it's the same work order as HLTH-05.

Method. All data collected 11 October 2026. Consumer AI answers came from DataForSEO's ChatGPT and Gemini scrapers and Google AI Mode, asked from Australia.
